  What: Claude Code + Slack MCP

  What: curl POST to Slack webhook

  Use When: You want automated posts from workflows

  Usage:
    1. Get webhook: https://api.slack.com/apps
    2. Add secret: SLACK_WEBHOOK_URL
    3. Done! Workflows auto-post

  Docs: docs/SLACK_SETUP.md

  What: Official GitHub + Slack integration

  Automation: ✅ Native GitHub Actions
  Use When: You want workflow status in Slack
